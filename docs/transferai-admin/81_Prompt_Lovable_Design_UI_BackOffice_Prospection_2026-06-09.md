# Prompt Lovable Court - Design / UI du Back Office Prospection

Date : 2026-06-09

## Objectif

Ce document fournit un prompt plus court et orienté design / UI pour affiner ou régénérer l'apparence du cockpit web "Back Office Prospection".

Il ne remplace pas le prompt technique.

Il sert à :

- améliorer la qualité visuelle
- mieux organiser les vues métier
- rendre l'application plus confortable pour un commercial ou un expert

## Prompt Lovable design / UI prêt à copier-coller

```text
Améliore le design et l’UX d’une application web appelée “Back Office Prospection TransferAI”.

Contexte :
Il s’agit d’un cockpit métier B2B utilisé par :
- des commerciaux
- des experts
- des admins opérationnels

Je veux un design de back-office haut de gamme, très lisible, très professionnel, orienté productivité.

STYLE VISUEL
- desktop-first
- clair, premium, sobre
- hiérarchie visuelle forte
- typographie sérieuse
- beaucoup de lisibilité
- cartes nettes
- tableaux élégants
- badges de statut
- filtres visibles et rapides
- navigation simple et rassurante
- aucune esthétique “startup générique” ou “landing page marketing”

PALETTE
- fond clair légèrement chaud ou neutre
- accent principal bleu profond ou marine
- accents secondaires orange discret / vert statut / rouge alerte
- contrastes accessibles

LAYOUT
Créer un layout d’application :
- sidebar verticale fixe
- topbar avec recherche, profil, filtres rapides
- zone centrale spacieuse
- cartes KPI en haut de dashboard
- tableaux métier sous les KPI
- drawers latéraux pour les détails

SECTIONS A SOIGNER
1. Vue d’ensemble
2. Prospects
3. Packs
4. Batchs V4
5. Réponses audit
6. Cas experts
7. Activité
8. Administration

COMPOSANTS A DESIGNER
- KPI cards
- data tables riches
- filter chips
- status badges
- detail drawers
- tabs de détail
- timeline d’activité
- alert banners
- empty states utiles
- loading states propres

COMPORTEMENT UX
- filtres toujours visibles
- densité d’information maîtrisée
- actions rapides facilement accessibles
- détails prospect et pack dans des drawers ou panneaux latéraux
- navigation rapide entre prospect, pack, batch et réponse audit
- design pensé pour gagner du temps en exploitation quotidienne

VUE D’ENSEMBLE
Je veux un dashboard qui donne en 5 secondes :
- combien de prospects sont prêts
- combien de packs attendent une validation
- combien de packs ont été envoyés aujourd’hui
- combien de batchs sont actifs
- combien de réponses audit attendent une lecture
- combien de cas experts sont ouverts

TABLEAUX
Les tableaux doivent être :
- filtrables
- triables
- paginés si nécessaire
- denses mais élégants
- lisibles même avec beaucoup d’informations

BADGES
Créer des badges clairs pour :
- statuts de prospect
- statuts de pack
- statuts de batch
- priorités
- niche active

DRAWERS / DETAILS
Le détail d’un prospect ou d’un pack doit s’ouvrir rapidement dans un drawer propre avec :
- résumé
- historique
- données liées
- actions rapides

RESPONSIVE
- très bon sur desktop
- bon sur tablette
- mobile secondaire mais propre

IMPORTANT
Je veux un rendu qui donne l’impression d’un vrai produit métier premium utilisé tous les jours par une équipe commerciale et des experts IA.
```

## Quand utiliser ce prompt

Utilise ce prompt :

- après le prompt technique
- ou quand l'app fonctionne déjà mais manque de qualité visuelle
- ou pour une itération purement UX/UI

## Résultat attendu

- une interface plus claire
- une meilleure navigation
- une perception plus premium
- un vrai confort d'exploitation quotidienne
